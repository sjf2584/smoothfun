# 스무스펀 (Smoothfun)

스트리머와 시청자가 함께 즐길 수 있는 빠르고 간단한 감각 테스트 미니게임 모음 웹사이트입니다.

## 🎮 포함된 게임
1. **완벽한 도형 그리기 (`perfect-shape.html`)**: 마우스로 원, 사각형 등을 얼마나 완벽하게 그릴 수 있는지 테스트합니다. (시각/운동 신경 테스트)
2. **색 맞추기 (`color-match.html`)**: 제시된 색상과 똑같은 색을 팔레트에서 찾아내는 게임입니다. (색각 테스트)
3. **절대음감 테스트 (`pitch.html`)**: 피아노, 기타, 플루트 소리를 듣고 어떤 음인지 맞추는 게임입니다. (청각 테스트)

## 🚀 배포 방법 (GitHub Pages)
이 저장소는 정적 웹 호스팅에 최적화되어 있습니다. HTML, CSS, 단순 Vanilla JS로만 구성되어 있어 빌드 과정 없이 즉시 배포 가능합니다.

1. **GitHub Repository 생성**: 내 계정에서 새 레포지토리를 만듭니다.
2. **코드 푸시**: 이 폴더의 코드들을 생성한 레포지토리에 푸시합니다.
3. **GitHub Pages 활성화**:
   - 레포지토리 `Settings` > `Pages` 메뉴로 이동
   - `Source`를 **Deploy from a branch**로 선택
   - `Branch`를 **main** (또는 master)로 선택하고 `Save` 클릭
4. **접속 접속**: 1~2분 후 `https://[내-깃허브-아이디].github.io/[레포-이름]/` 으로 접속하여 게임을 즐기면 됩니다.

## 💸 수익 창출 (Google AdSense)
각 HTML 파일 구조 안에 AdSense 반응형 광고 슬롯 레이아웃이 미리 잡혀있습니다. 
1. `privacy.html`의 운영자 정보를 실제 본인 정보로 수정합니다.
2. 구글 애드센스에서 고유 Publisher ID(`pub-0000000000000000`)를 발급받아 각 HTML 파일의 주석 처리된 스크립트 코드를 교체하고 주석을 해제합니다.
3. 광고 단위 ID(`data-ad-slot`)를 교체하면 즉시 광고 수익 창출이 가능합니다.
