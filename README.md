# 스무스펀 (Smoothfun)

누구나 가볍게 즐길 수 있는 빠르고 간단한 감각 테스트 미니게임 모음 웹사이트입니다.

## 🎮 포함된 게임
1. **완벽한 도형 그리기 (`perfect-shape.html`)**: 마우스로 원, 사각형 등을 얼마나 완벽하게 그릴 수 있는지 점수로 평가합니다. (시각/운동 신경 테스트)
2. **색 맞추기 (`color-match.html`)**: 제시된 색상과 똑같은 색을 팔레트에서 찾아내는 게임입니다. (색각 테스트)
3. **절대음감 테스트 (`pitch.html`)**: 피아노, 기타, 플루트 소리를 듣고 어떤 음인지 맞추는 게임입니다. (청각 테스트)
4. **눈 감고 초 맞추기 (`stopwatch.html`)**: 눈을 감고 정확히 지정된 초에 도달했을 때 멈추는 게임입니다. (시간 감각 테스트)
5. **침팬지 기억력 테스트 (`memory.html`)**: 화면에 잠시 나타났다 사라지는 숫자의 위치를 순서대로 기억해 누르는 게임입니다. (작업 기억력 테스트)
6. **가짜 신호 참기 (`fakeout.html`)**: 무작위 낚시 신호들을 무시하고 진짜 신호에만 반응해야 하는 게임입니다. (억제/반응 속도 테스트)
7. **뇌정지 컬러 테스트 (`stroop.html`)**: 단어의 의미가 아닌 단어에 칠해진 글자색만을 빠르게 판별하여 누르는 게임입니다. (인지 부하 테스트)
8. **미친 에임 트래킹 (`aim.html`)**: 마우스 에임을 요동치는 타겟에 계속해서 유지해야 하는 극한의 게임입니다. (피지컬/동체시력 테스트)
9. **뇌정지 멀티태스킹 (`multitask.html`)**: 왼손으로는 블록을 피하면서 오른손으론 사칙연산을 풀어야 하는 다중 작업 테스트입니다. (분할주의력 테스트)
10. **리듬 기억 테스트 (`echo.html`)**: 무작위로 제시되는 박자를 듣고 그대로 따라 치는 테스트입니다. (리듬 및 단기 기억 테스트)
11. **마인드 플립 (`mindflip.html`)**: 매 턴마다 시시각각 뒤집히는 논리 규칙에 맞춰 상황을 판단하는 테스트입니다. (인지 유연성 테스트)
12. **극한의 휠 생존 (`scroll.html`)**: 오직 마우스 휠(스크롤)만을 위아래로 굴려 다가오는 장애물 틈을 통과하며 생존하는 테스트입니다. (세밀 조작 테스트)
